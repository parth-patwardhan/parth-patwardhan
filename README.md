## Featured Projects

### [StemAgent — Self-Specializing AI Research Agent](https://github.com/parth-patwardhan/Stem-Agent-JetBrains)
Agentic framework built with Claude Opus implementing a custom **OBSERVE → ARCHITECT → VALIDATE → ITERATE → EXECUTE** lifecycle. The agent autonomously reconfigures its own reasoning architecture at runtime based on the task domain — no human intervention required. Uses LangGraph-style orchestration, REST APIs, and MCP for tool integration. Built as the JetBrains AI Engineering challenge submission.

### [SafeDAG — Collision-Aware Trajectory Prediction](https://github.com/parth-patwardhan/parth-patwardhan) *(M.Sc. Thesis)*
GNN/GAT model for autonomous driving, evaluated on the nuScenes dataset.

| Scenario | Baseline collision rate | SafeDAG collision rate |
|---|---|---|
| Clean | 26.0% | **1.6%** |
| Adversarial | 69.9% | **6.6%** |

Best ADE: **3.173m** · Supervised by Prof. Dr. Bin Yang, ISS Stuttgart.

### [AI Resume Analysis Platform — RAG Pipeline](https://github.com/parth-patwardhan/ResumeHelpBackend)
Full RAG pipeline as a microservices architecture: document ingestion → chunking → BERT embedding generation → vector DB indexing (Pinecone, Weaviate) → semantic retrieval → GPT-3.5 generation. Deployed on Google Cloud Platform. Scaled to **500+ concurrent users**.

### [Road-Ware-Detection](https://github.com/parth-patwardhan/Road-Ware-Detection) *(B.E. Thesis — Published)*
Real-time pothole and driver drowsiness detection for the Government of India using YOLOv5 + monocular camera. **92% accuracy**, **45% inference speedup** via pruning and quantisation for edge deployment.
